西理工教务系统 免验证码登录 使用说明书
====================================================
适用网站：https://jwgl.xaut.edu.cn 教务系统
版本：1.3.3（2026-08）

一、这是什么
----------------------------------------------------
本工具让教务系统登录时"账号、密码、验证码"全部自动填好，
你只需点一下"登 录"。
原理：本地运行一个验证码识别服务（启动识别服务.exe），
配合浏览器里的 Tampermonkey 脚本：打开登录页后脚本自动填
学号密码，并把当前验证码图片发给本地服务识别后填入。
验证码每次刷新都会重新识别，无需人工输入。

二、运行环境
----------------------------------------------------
- Windows 10 / 11（64 位）
- Edge / Chrome / Firefox 浏览器（推荐 Edge）
- 不需要安装 Python 或其他任何软件

三、安装步骤（一次性，约 5 分钟）
----------------------------------------------------
【第 1 步】解压本压缩包到任意文件夹（路径建议全英文，
        如 D:\xaut-login，避免个别电脑中文路径出问题）
【第 2 步】双击 "启动识别服务.exe"
         - 成功：没有窗口或黑窗口一闪而过，服务已在后台运行
         - 验证：浏览器访问 http://127.0.0.1:8765/health
           显示 {"status":"ok"} 即服务正常
【第 3 步】Edge 打开 https://microsoftedge.microsoft.com/addons
         搜索 Tampermonkey → 获取 → 添加扩展
【第 4 步】点浏览器右上角 Tampermonkey 图标 → 管理面板
         → "实用工具"标签 → "从文件导入"
         → 选择本文件夹里的 xaut-login.user.js → 安装

四、日常使用
----------------------------------------------------
1. 打开 https://jwgl.xaut.edu.cn/jsxsd/ 登录页
2. 第一次使用会弹窗两次：分别输入你的学号和密码
   （只保存在你这台电脑的浏览器里，不经过任何第三方）
3. 以后每次打开页面，账号、密码、验证码都会自动填好
4. 点"登 录"即可

【新增功能】
1. 云更新：脚本每天自动检查一次新版本，有新版本时页面右下角会弹出提示，
   点击提示即可更新；Tampermonkey 管理面板里也可以手动"检查更新"。
2. 按周导出课表：登录教务系统后打开"个人课表"页面，右下角会出现绿色的
   "📅 导出课表"按钮。选择第几周后，可直接下载 A4 横向 PDF，也可下载格式化 Excel 文件或打印网页版课表。

五、常见问题
----------------------------------------------------
Q1：登录页打开后什么都没自动填？
A：按顺序检查：
   ① 识别服务是否在跑：访问 http://127.0.0.1:8765/predict
     不是 405 就重新双击一次"启动识别服务.exe"
   ② Tampermonkey 图标是否是彩色的（灰色=脚本被禁用）
   ③ 脚本是否已导入（管理面板里能看到"西理工教务验证码自动填充"）
   ④ 确认打开的是 https://jwgl.xaut.edu.cn 而不是其他域名

Q2：提示验证码错误，登录失败？
A：正常现象，验证码偶尔识别错。点一下验证码图片换一张，
   它会自动重新识别填入，再点登录即可（通常 1-2 次内成功）。

Q3：怎么改学号或密码？
A：打开登录页后，点击右下角的“登录助手”按钮，输入新的信息并保存即可。

Q4：开机自启？
A：双击一次 "安装开机自启.bat"，以后登录 Windows 自动启动
   识别服务。取消自启：删除启动文件夹（Win+R 输入
   shell:startup 回车）里的"西理工验证码服务"快捷方式。

Q5：识别服务怎么关掉？
A：任务管理器 → 找到 "启动识别服务" 进程 → 结束任务。
   不影响任何其他软件。

Q6：换了台电脑？
A：把本压缩包拷过去，按"三、安装步骤"重新来一遍即可。

六、卸载
----------------------------------------------------
1. Tampermonkey 管理面板 → 删除本脚本
2. 删除"安装开机自启.bat"创建的快捷方式（见 Q4）
3. 任务管理器结束"启动识别服务"进程（见 Q5）
4. 删除整个解压文件夹

七、安全说明
----------------------------------------------------
- 学号和密码只存在于你自己的浏览器（Tampermonkey 存储）和
  教务系统服务器之间，识别服务只接收验证码图片，收不到密码
- 识别服务只监听本机 127.0.0.1，不对外网开放
- 本工具为学习用途，请勿用于批量抓取等违规操作
